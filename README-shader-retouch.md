
## v5 当前默认输出映射（替代 v4 全局线性归一化）

删除峰值归约，单个亮点／超限颜色不再压暗全图。调色后的线性亮度 Y≤0.72 保持不变，超过阈值通过连续指数肩部趋向 0.995；保留前段既有明暗基调曲线。高亮区域适度降低色度（最多 18%），其余中间调颜色保持；超色域像素在 OKLab 中降低色度拟合 SDR 色域，再编码 sRGB，最后执行受通道余量限制的锐化。不是完整 AgX/ACES 实现。

本节替代历史版本的最终映射说明。GPU 分段名称改为 `output_sdr`，不再有 `linear_sdr` 或峰值统计，不增加 CPU 读回。已验证中间调近似恒等、高光映射单调、孤立亮点不影响其他像素，并验证三张样本的三种预设及塑形开关。重新处理现有输出请使用 `--overwrite`。
